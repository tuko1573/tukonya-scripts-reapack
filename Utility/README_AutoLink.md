# TUKONYA Auto Link

同じ「Link Ch」を選んだトラック同士で、オートメーションをリンクすることができます。
VCAと違いLeaderトラックを別途用意する必要がないのが特徴です。

---

必要なもの

・REAPER バージョン7.79以降
・ReaPack https://reapack.com/

---

導入

①(他のツールで設定済の場合②へ)
[拡張→ReaPack→Import Repositories...]をクリックし、出た画面でこのアドレスを入力し[OK]
https://raw.githubusercontent.com/tuko1573/tukonya-scripts-reapack/main/index.xml

②
[拡張→ReaPack→Browse packages...]からFilter:に「tukonya」と検索。
「TUKONYA Auto Link」を[右クリック→Install]、[Apply]をクリック。

③
将来の更新は[拡張→ReaPack→Synchronize packages]で行えます。

---

自動起動の設定

①
[アクション→アクションリストを開く...]の検索欄に「tukonya」と入力し、
「TUKONYA_Auto Link (Install Startup)」を選んで[実行]。

②
自動起動をやめたいときは、「TUKONYA_Auto Link (Uninstall Startup)」を実行してください。
